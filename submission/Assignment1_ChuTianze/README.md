# Assignment 1 - Email App

Developer: Chu Tianze

## Contents
- EmailApp/: complete Android Studio project source and Gradle wrapper.
- app-debug.apk: debug APK for installation on Android API 24 or above.
- Video/: recorded demonstration video in MP4 format (approximately 1 minute 59 seconds).

## Open and build
Open EmailApp/ in Android Studio, install Android SDK platform 37 and let Gradle sync. The included Gradle daemon configuration requests JDK 25; Java compilation compatibility is 17. Android Studio creates local.properties for the local SDK path.

To build from a terminal: cd EmailApp, then run ./gradlew :app:assembleDebug.
